One line, 81 characters: a pickup line a vending machine would use on a passing human. It has 47 snacks and a strict no-refunds policy — but for you, it would jam its own coil.

The entry:

> `I have 47 snacks and a strict no-refunds policy, but for you I'd jam my own coil.`

81 characters, one line, valid UTF-8 — inside the 200-character gate in `RULES.txt`.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```

Writes the pickup line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`) and validates it against the gate (1–200 characters, single line, non-whitespace, valid UTF-8) before and after writing.
